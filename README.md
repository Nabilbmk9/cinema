# cinema — Test technique Django

Objectif : application Django permettant de gérer films, auteurs et spectateurs,
avec interface d’administration, API REST et intégration TMDb.

## Stack cible
- Python 3.12
- Django 4.2+
- Django REST Framework
- PostgreSQL
- Docker / docker-compose

Le projet est construit étape par étape conformément à l’énoncé.
